# 📘 JavaScript Level 1 Projects (1–5)

This repository contains the first five projects from my JavaScript learning journey. These beginner-friendly projects focus on strengthening core programming concepts, logical thinking, and basic DOM manipulation.

Each project is designed to build a solid foundation before moving to more advanced JavaScript and full-stack development.

---

## 🚀 Projects Included

### 1️⃣ Multiplication Table Generator
- Generate multiplication tables from user input
- Practice loops and arithmetic operations

### 2️⃣ Palindrome Checker
- Check whether a number or string is a palindrome
- Practice conditional statements and string manipulation

### 3️⃣ Factorial Finder
- Calculate the factorial of a number
- Strengthen understanding of loops and mathematical logic

### 4️⃣ Random Quote Generator
- Display random quotes dynamically
- Practice arrays, `Math.random()`, and DOM manipulation

### 5️⃣ Word Counter Tool
- Count words and characters
- Practice string methods and DOM interaction
